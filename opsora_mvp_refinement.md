## EXECUTIVE SUMMARY

### Scope of Audit
Performed a complete cross-check of the Opsora codebase: **15 API route files** (190K+ bytes), **43 frontend page components**, **3 role-based layouts** (dashboard/tenant/staff), **879-line Drizzle schema** (40 tables), **304-line Zod validation layer**, **1 middleware file**, and **1 API client library**.

### Architecture Snapshot
| Layer | Technology | Status |
|---|---|---|---|
| **Frontend** | Next.js 16 (App Router) + TailwindCSS v4 + Framer Motion | ✅ Functional |
| **Backend** | Fastify + Drizzle ORM + better-sqlite3 | ✅ Functional |
| **Auth** | Custom JWT (no Clerk) + cookie-based middleware | ⚠️ Partial |
| **DB** | SQLite (dev) — Design doc specifies PostgreSQL | ⚠️ Mismatch |
| **Monorepo** | Turborepo + npm workspaces | ✅ Configured |

### Critical Findings (TL;DR for Stakeholders)

1. **Payment system has a math bug** — `balanceAmount = totalAmount - rentAmount` instantly marks invoices as paid on creation. Revenue data is unreliable.
2. **No Owner/Proprietor dashboard** — The admin dashboard shows operational metrics but zero P&L, ROI, or per-property financial analysis. Owner persona is unserved.
3. **RBAC is shallow** — Middleware checks `role` cookie (client-side spoofable). No granular permission matrix. Staff can't be sub-typed (cook vs electrician).
4. **No UPI/Cash digital ledger** — Design doc says "No Razorpay" but `paymentMethod` enum still includes `card` and `payment_gateway` column exists. Zero bank statement OCR, zero UPI QR generation.
5. **Tenant food module has no Food nav link** — The tenant layout nav doesn't include `/tenant/food`, meaning 6 food pages are orphaned and unreachable from the sidebar.
6. **Staff portal has no dashboard page.tsx** — `/staff` has no `page.tsx` (only a `.bak` file), so the staff landing page 404s.
7. **Visitor management has schema & API but ZERO frontend** — No pages exist for the `visitors` table anywhere in the web app.
8. **No notice period / move-out tracking UI** — Schema has `noticeDate`, `moveOutDate`, `noticePeriodDays` but no frontend form or dashboard widget surfaces them.
9. **No security deposit tracking UI** — `depositPaid` and `depositBalance` exist in schema but no dedicated deposit management view.
10. **WebSocket is echo-only** — `/ws` echoes messages; no broadcast infrastructure for real-time payment/IoT/complaint updates.

### Competitive Landscape

| Competitor | Weakness | Opsora's 10x Opportunity |
|---|---|---|---|
| **HostelMate** | Desktop-only, no IoT, no food management | Mobile-first tenant app, IoT water/energy, full food lifecycle |
| **PG Life** | Payment-aggregator dependent (MDR costs) | Zero-MDR UPI proof flow, cash digital ledger |
| **Excel / WhatsApp** | No automation, manual tracking, data silos | Automated invoicing, SLA monitoring, WhatsApp bot integration |
| **Generic CRMs** | Not built for Indian PG compliance (KYC/police verification) | Aadhaar/PAN OCR, police verification tracking, BLR-specific flows |
